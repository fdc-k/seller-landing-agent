# Seller Landing Agent

Whatnot 观察台的 Windows / macOS 卖家专属落地程序公开分发仓库。

本仓库只发布程序源码和安装脚本生成工具，不包含观察台服务端、任何卖家 Token、安装凭据、实际机器信息、中转配置或私钥。代码快照来源和逐文件摘要见 `SOURCE.json`。本仓库不是 Whatnot 官方 SDK。

## 运营人员怎样安装

管理员先在私密环境准备账号专属安装计划、观察台公网 HTTPS 安装入口和美国中转，然后私下发放 Windows 或 macOS 的一条安装命令。运营人员只在对应卖家自己的机器上运行这一条命令。

**公开安装入口已发布：Windows 使用 [install.ps1](install.ps1)，macOS 使用 [install.sh](install.sh)，文件摘要见 [entry-manifest.json](entry-manifest.json)。**

执行入口仍需管理员提供可信的观察台 HTTPS 地址和该账号安装脚本的 SHA256，并在提示时粘贴私密的账号安装链接。入口仅从指定地址下载、拒绝重定向，并在执行前校验脚本摘要。实际一条安装命令应固定公开仓库的 Git 提交版本，不能直接把 `main` 当作固定版本。

账号绑定和安装凭据不能放进公开 GitHub 仓库；仅下载本仓库不会自动接入任何观察台。本次源码发布没有替任何真实卖家部署中转。管理员也可直接发放一条私密安装命令。

安装器自动下载并校验固定版本依赖，在本机生成独立密钥、注册固定账号、建立反向 SSH 隧道、安装当前用户后台任务并上报系统时区。无需提前配置 VLESS，也无需给家用电脑开放入站端口。落地机必须能主动访问观察台 HTTPS 和美国中转 SSH。

Windows 需要保持该用户已登录且电脑不休眠；后台任务名称为 `WAO Seller Landing`。macOS 使用该用户的 LaunchAgent。当前不是登录前运行的系统服务。

## 账号隔离

- 观察台加密保存 Personal access token，安装包和安装命令不包含 Token。
- 观察台只在认证该账号已登记的机器 Ed25519 TLS 公钥后发送请求。
- 中转只把固定入口转给对应机器，不能直出或自动切到其他卖家。
- 落地网关校验账号、机器、卖家身份、HMAC 和出口策略，只允许预定义 Seller API 读取。
- Token 会在每次请求期间到达该卖家的落地网关内存，由网关向 Whatnot 发出请求；不持久化到落地磁盘。
- 同一 Windows/macOS 用户不能直接用另一个安装凭据覆盖原账号绑定。

软件证明的是登记密钥的持有者身份，不能证明机器的法律所有权，也不能阻止拥有本机管理权限的人复制密钥。

## 动态出口 IP

当前源码支持国家策略：新出口 IP 属于账号配置的国家，就自动更新观测结果并恢复，不额外核验卖家身份、不要求人工确认。账号与机器公钥继续固定绑定。国家不同或未知时暂停并自动重试。首次安装仍需核验卖家身份，正常业务读取原有身份检查仍保留。固定 IP 模式继续支持。详见 [动态 IP 行为](DYNAMIC-IP-DESIGN.zh-CN.md)。

需要观察台和落地程序同时升级，并在私密配置中批准国家策略；公开源码发布不代表生产部署或真实机器已经接通。

## 管理员文件

- `services/seller-landing/`：安装器、后台监督程序、只读 TLS 网关和固定操作列表。
- `services/seller-machine-info/`：签名机器时区上报。
- `scripts/seller-landing-bootstrap.mjs`：生成 Windows / macOS 单命令安装所需脚本，输入是私密安装凭据与固定 SHA256 的依赖清单。
- `scripts/seller-landing-assets.mjs`：构建公开程序资产并校验固定版本第三方依赖摘要。下载的第三方二进制未随本仓库发布。

实际账号计划、短期安装凭据、中转 SSH 用户、公钥登记和 API Token 配置仍由观察台私密部署管理；本仓库不包含这些管理权限。

## 本地检查

安装 Node.js 22.23.3 或更新的兼容版本后执行 `npm test`。检查在临时目录生成公开资产，不访问 Seller API、不安装后台任务、不连接真实中转。

真实 Windows / macOS 完整安装、中转连通与账号核验需要另外验收；通过离线测试不代表真实账号已接通。
